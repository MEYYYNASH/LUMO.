# LUMO — Premium Dark-First Music & Video Player

LUMO is a high-fidelity music and video streaming application featuring authorized media downloads, interactive waveform scrubbing, custom playlists, Khmer artist directory (VannDa, Tena, Suly Pheng, G-Devith, Preap Sovath, Sinn Sisamouth), and 5 curated themes.

## Features
- **Hi-Fi Audio & Video Streaming**: Smooth playback with waveform scrubbing and live subtitle cues.
- **Khmer Artist Directory**: Explore Cambodia's top artists, hip-hop icons, and golden era legends.
- **Authorized Media Downloads**: High-bitrate offline storage management.
- **Curated Themes**: Switch between Obsidian Dark, Solar Amber, Neon Echoes, Velvet Drift, and Emerald Luxe.
- **Playlists & Library**: Manage favorites and custom playlists.

## Tech Stack
- React 19 + TypeScript
- Vite + Tailwind CSS v4
- Lucide React Icons
